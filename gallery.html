The examples, in the order to learn them

Every example world in examples/, as a route: what each one teaches, what it needs first, how to run it and what you should see, and one thing to change and predict before you run it again. Each opens in one workshop tab, where the button Start this world over on the title card puts it back as it began; the manual explains the parts.

Each card says what you do — try it run it and predict, change it change one thing and predict, read it read the robots to predict, build it train a robot of your own — and, apart from that, how much is inside. Tick tried on a card and this browser remembers it.

First steps

One visible change, a small robot, a predictable result.

1 🔀 Swap numbers

A robot does one thing to what it is given, and stops when its thought no longer fits.

try it inside: small, 1 robot, the longest 6 steps

Run: Give the leaning scale to the Swap robot: it swaps the two pans, the scale tips the other way, and the robot stops after one round.

Change and predict: Give it the OTHER scale, the one already the right way round. Predict: does it run, and why not?
